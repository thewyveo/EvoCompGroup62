Research design
RQ: How does mutation strategy affect convergence when evolving a bounded direct tree genome toward multiple target robot morphologies?
Hypothesis: mixed structural mutation reaches lower fitness because it explores topology more broadly.
Variant A — point_only: mutate_replace_node.
Variant B — mixed: uniformly chooses replace-node, subtree-replacement, shrink, or hoist.
Crossover disabled in both variants to isolate mutation.
Reason: supplied crossover_subtree produced unchanged parents in 100/100 tests; ARIEL source was not modified.
EA configuration
Population: 50
Generations: 100
Evaluations/run: 50 + 100×50 = 5,050
Seeds: 11, 22, 33, 44, 55
Five runs per EA variant and five random-search runs
Tournament parent selection, size 3; lower fitness wins
Elitist (μ + λ) survivor selection
One mutation attempt per offspring
Maximum 20 total modules
Maximum depth 12
Python and NumPy RNGs seeded
Minimisation explicitly configured
Evolution pipeline
Generate TreeGenome
Store genome.to_dict() in ARIEL Individual
Deserialize using TreeGenome.from_dict()
Convert to NetworkX only during evaluation
Fitness = mean target distance + one population standard deviation
Select parents → produce/mutate offspring → evaluate → keep best 50
ARIEL automatically saves each run to SQLite
